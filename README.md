# Blackpeak Depths
A 2D metroidvania where you play as a raven trying to find the origin of a mysterious pandemic that turned animals into monsters.

This game reuses a lot of common mechanics of metroidvanias.

## The Story
A misterious pandemic turned animals into monsters. You, a little raven need to find the cause of the end of the world. You heard that it surely comes from the core of the mountain Blackpeak.
